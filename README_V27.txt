STUDIO RB V27 — MOBILE IMAGE + CONCLUÍDOS

1. Troca de imagem no celular
- seletor de arquivo agora é NATIVO: o input real fica sobre o botão.
- não depende de JavaScript .click(), que falha em alguns Safari/iPhone.
- removido capture=environment para permitir Galeria/Fotos normalmente.
- aceita image/*, HEIC e HEIF.
- limite 40 MB.
- servidor otimiza para WEBP.
- erro específico se o aparelho enviar um HEIC que o servidor não conseguir converter.

2. Agendamentos concluídos
- ao clicar Concluir, o agendamento some imediatamente da visão "Todos".
- continua disponível na aba "Concluídos" para histórico.
- também deixa de aparecer na agenda ativa do dia.
